Known errors and error codes

What the numbers Monster Hunter Tri shows mean on {name}, and what to do about them. The server's own refusals are a sentence, not a number (below). "Seen" marks a cause we met on a console; "likely", one read from the game's code. Back to playing online.

Logging in (the Nintendo login)

CodeWhat happenedWhat to try
20100The login couldn't reach the server (no connection, a missing or wrong patch, the server down). Seen.Check the patch (this server's, your disc's) and the Internet connection
23xxxThe login answered with a web error (23404: not found, 23500: a server error). Seen. Tell the operator, with the number
20101The login's answer couldn't be read. Likely.Tell the operator

Connecting to the server

CodeWhat happenedWhat to try
11601The server's name couldn't be looked up. Likely. Check the Internet connection; if it lasts, tell the operator (their DNS records)
11602–11611, 11618The secure connection failed: the game doesn't trust the server's certificate (11604–11607: its name, authority, chain or date). Likely. Get this server's patch again: yours is missing, another server's, or an old one
11617The server couldn't be reached. Likely.An unpatched game, or the server is down
11612, 11613The server closed or reset the connection. Seen. Retry; if it lasts, tell the operator
11614–11616The connection dropped. Likely.Check the connection, retry
11620–11625The link to the server was lost (11625: any other reason). Seen, after a server stop.Retry; if many players see it, the server is down or restarting

Cities and hunts (console to console)

Hunts are console to console: the server only introduces you, and relays your traffic when your router can't.

CodeWhat happenedWhat to try
11669Entering a city, its host never answered. Seen when entering a city at the very moment it is created (its host is still setting it up): rare.Retry a few seconds later
11674No word from the host or the server in time. Seen: Dolphin fast-forwarded (the game's time runs ahead), a connection cut for more than 15 seconds, the server stopped during a quest. In Dolphin, never fast-forward; otherwise rejoin
11682Joining, your console couldn't open its connection. Seen with two Dolphins on the same computer that picked the same port by chance: rare, and not the server.Retry
11688Joining another player: no direct path between you. Seen. Retry: the server relays such pairs
11686Joining another player: they never showed up. Likely.Retry
11687Joining another player: the server's NAT negotiation didn't answer. Likely. Your network must not block UDP; the server may be down
11668, 11676, 11677, 11679Another player's link was lost, or they left. Likely. Retry
Any other 116xxYour console's own network trouble. Never seen with this server. Retry; if it comes back, tell the operator, with the number

Sentences instead of a number

When the server refuses something, it says why, under its name: an unconfigured or not-ready server, a disc version not supported (Monster Hunter Tri, European or US), a game not patched for this server, a console not allowed or banned, a login not through this server (check the patch), maintenance (the operator's text). In the game, short messages: a city full or gone, a quest full or gone, a wrong password, a seat taken, "You can't go there now", "Too fast: please wait a moment", a world server's HR limit.

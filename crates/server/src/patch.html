How to play Monster Hunter Tri online on this server, {domain}.

What you need

  • Monster Hunter Tri: the European (RMHP08) or US (RMHE08) disc; the Japanese one isn't supported.
  • Either Dolphin (any recent version), or a Wii that runs homebrew (the Homebrew Channel) with Riivolution to patch a disc, or a USB loader for an image patched once.
  • This server's patch, below. It points the game at this server and makes it trust this server's certificate: nothing else to set, no DNS, no hosts file. It holds no game data.

Patching the game

Take the file for your disc and the way you play.

  • Dolphin: the Riivolution file ({riivolution}), into Load/Riivolution/riivolution in Dolphin's user folder. Right-click the game, Start with Riivolution Patches, check that the server's option is on, Start. Without copying, Open Riivolution XML takes the file directly.
  • Wii, disc: the same Riivolution file, into the riivolution folder at the root of the SD card. Launch Riivolution from the Homebrew Channel, insert the disc, check the server's option, Launch.
  • Wii, USB loader: patch your image once on a computer with Wiimms ISO Tools (wit; Linux, macOS, Windows) and the wit file for your disc ({wit}), then copy the new image to the loader's drive. For a European disc: 
    wit extract mh3.iso mh3-patched --psel data
wit dolpatch mh3-patched/sys/main.dol xml={domain}-RMHP08.xml
wit copy mh3-patched mh3-patched.wbfs
    On a Mac with Apple Silicon, macOS stops wit at once ("killed"): run it as arch -x86_64 wit … instead. (Checked with Dolphin, not yet on a Wii.)
  • Wii, USB loader, without a computer (untested on a Wii): the Gecko file ({codes}), into the codes folder at the root of the SD card; in USB Loader GX or WiiFlow, turn Ocarina (cheat codes) on for the game. If the game doesn't reach the server this way, patch the image with wit instead.

This patch reaches only this server. The Gecko file has no server in its name: keep one server's at a time in codes. If the server's operator ever starts over with a new certificate, download the patch again.

Dolphin settings

  • Run at normal speed, always. Never fast-forward (Tab) online: the game drops itself after 90 seconds of its own time without hearing from the server (error 11674), and fast-forward makes its time run ahead.
  • Leave Verify certificates on (Dolphin's network settings): the patch carries this server's own certificate authority, which the game checks against, like a Wii.
  • Two Dolphins on one network should have different MAC addresses (Config → Wii → Wireless MAC).

Your support code is your account

The first time you connect, the server gives your save an online support code. It is how the server knows your console: whoever has it plays as you, with your hunters, friends and messages. Never share it, nor your save file. Lost (a deleted save), it can't be recovered: the server keeps only a fingerprint of it, never the code.

Playing with others

Hunts are console to console. The server first tries to connect you directly, and relays your traffic when your router can't: you don't need to open ports at home. If joining a city fails for everyone at once, tell the server's operator.

Errors

The game shows a number; the server's own refusals (an unpatched game, maintenance, a ban…) are a sentence instead. What each number means, and what to try: known errors and error codes.
